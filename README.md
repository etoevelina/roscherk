# Росчерк — головоломки одной линией и английские слова

Играть: **https://etoevelina.github.io/roscherk/** (открыть в Safari на iPhone → «Поделиться» →
«На экран „Домой“»).

Мобильная логическая игра для iPhone Safari: каждое решение рисуется пальцем **одной непрерывной
линией**, а четвёртый режим — английский акростих для прокачки словарного запаса. Три режима
головоломок по 100 уровней кампании, «Ежедневная» и «Бесконечность», плюс 100 уровней «Слов»,
прогресс и незавершённая партия сохраняются на устройстве. Работает офлайн после установки
на экран «Домой». Без фреймворков, внешних шрифтов и CDN: HTML + Canvas 2D + ванильный JS,
собранный esbuild в один `dist/index.html`.

Единственный источник истины по правилам, контрактам и форматам — [`docs/SPEC.md`](docs/SPEC.md).

## Режимы

- **Маршрут** (`zip`) — одна дорожка от 1 до K через **все** клетки, числа строго по порядку,
  сквозь толстые линии (стены) нельзя. У каждого уровня ровно одно решение.
- **Потоки** (`flow`) — соедини пары точек одного цвета дорожками, не пересекая их, и заполни
  **все** клетки. Проведение по чужой дорожке обрезает её. Звезда — без подсказок и за число
  ходов, равное числу потоков.
- **Один штрих** (`stroke`) — обведи фигуру, пройдя **каждый** отрезок ровно один раз, не отрывая
  пальца. Модификаторы: стрелки (только в их направлении), фиксированный старт, замкнутый росчерк.
- **Карандаш** (`draw`) — физические головоломки с рисованием на движке matter-js: всё, что
  нарисовано пальцем, становится твёрдым телом. Два типа: довести шарик до цели (мостики, грузы,
  качели, шары, ветер, лёд, шипы) и защитить банку мёда от роя ос и жуков. 60 рукописных уровней в
  четырёх главах, каждый проверяется симуляцией в Node (`npm run draw`): эталон побеждает,
  бездействие — нет. Чернила ограничены, звезда — за экономию.
- **Слова** (`words`) — английский акростих как в Crostic.

Оформление — дизайн-система WORDS 1.2 (`docs/DESIGN.md`): тёплый фарфор, стеклянные 3D-объекты
(`assets/art/*.webp`, производные от PNG-мастеров через `python3 -I tools/art.py`), нижняя
навигация «Главная · Режимы · Ежедневная · Статистика», карта уровней, профиль. Скриншот любого
экрана для проверки вёрстки: `node tools/shot.mjs <имя> "screen=stats&demo=1&theme=dark"`.
  Под цитатой — английские определения слов. У каждой буквы свой номер: буква, введённая в любую
  клетку, встаёт во все клетки с этим номером, поэтому отгаданные слова открывают цитату, а цитата
  помогает со словами. После отгадки — перевод слова, в конце уровня — цитата с переводом и все слова
  с определениями. 20 тем по 5 уровней («Дом и быт», «Еда и кухня», …, «Язык и общение»), около 700
  слов уровня B2–C1; тему можно начать в любой момент. Подсказки — шторка: открыть букву, проверить
  ответ, показать перевод.

## Как играть

1. На главном экране выбери режим — «Играть» продолжает незавершённую партию или открывает
   следующий непройденный уровень; тап по названию открывает список уровней (окно из трёх
   открытых после последнего пройденного).
2. Рисуй пальцем: дорожка растёт на соседнюю клетку/точку под пальцем, возврат по своей дорожке
   укорачивает её. Отпустил — дорожка остаётся, продолжить можно с её конца.
3. Нижняя панель: **Отменить** (стек из 50 снимков), **Сбросить** (5 с можно отменить),
   **Подсказка** (второй тап в течение 2 с подтверждает; звезда за попытку не засчитается),
   **Пропустить** появляется после 3 сбросов или 90 с без изменений.
4. Победа — оверлей с временем, лучшим результатом и кнопками «Дальше» / «Повторить».
5. **Ежедневная** — один уровень в день, режимы чередуются, серия растёт при игре каждый день.
   **Бесконечность** — режим или микс, сложность растёт с серией; подсказка и пропуск её обрывают.
6. Настройки (шестерёнка): звук, тема, номера на точках в «Потоках», перенос прогресса кодом,
   сброс прогресса, версия сборки.

Все 290 уровней каждого режима сгенерированы офлайн детерминированно от seed и вшиты в сборку;
в рантайме генераторов нет.

## Разработка

Нужен Node 20+. Единственная зависимость — `esbuild`.

```sh
npm install
npm test            # node --test tests/ — солверы, генераторы, ввод, рендер-smoke, данные уровней
npm run gen         # tools/generate.mjs → src/data/levels.json (5–6 минут: zip/flow 8×8–9×9 решаются долго)
npm run words       # tools/words.mjs → src/data/words.json (уровни «Слов» из tools/words/themes/*.json, ~30 с)
npm run draw        # tools/draw.mjs → src/data/draw.json (уровни «Карандаша» из tools/draw/levels/*.json; --only N, --trace N)
npm run verify      # tools/verify.mjs — перепроверка всех уровней: валидность, уникальность, difficulty
npm run build       # tools/build.mjs → dist/ (index.html ≤ 1 МБ, levels ≤ 400 КБ, иконки через qlmanage/sips)
npm run dev         # http://127.0.0.1:8765 — статика из dist/ для отладки на Mac (SW на localhost не регистрируется)
```

`npm run gen` детерминирован: тот же `masterSeed` (по умолчанию `20260101`) даёт тот же набор
уровней (меняется только `meta.generatedAt`). Прогресс хранится по `id` уровня (sha1
содержимого), поэтому замена уровня — это новый `id`; наборы после релиза — append-only.

Структура: `src/core/*` — ядро (rng, трассировка свайпа, хранилище, звук, тема, холст),
`src/modes/<id>.js|.gen.js|.solve.js` — режим, его генератор и солвер, `src/ui/*` — экраны,
`tools/*` — генерация, проверка, сборка, иконки, `tests/*.test.mjs` — тесты `node:test`.

## Публикация на GitHub Pages

Сборка — статика с относительными путями (`./`), поэтому работает из любой подпапки.
Основной способ — одной командой:

```sh
npm run deploy      # сборка + dist/ → ветка gh-pages репозитория origin (tools/deploy.mjs)
```

Игра откроется по адресу https://etoevelina.github.io/roscherk/ (Settings → Pages → ветка
`gh-pages`, папка `/`). Ниже — прежние варианты вручную.

**Ветка `gh-pages` из папки `dist`** (без Actions):

```sh
npm run gen && npm run verify && npm run build
git add -f dist && git commit -m "Сборка"
git subtree push --prefix dist origin gh-pages
```

Затем в репозитории: Settings → Pages → Source: *Deploy from a branch*, ветка `gh-pages`, папка `/ (root)`.
Игра откроется по адресу `https://<user>.github.io/<repo>/`.

**GitHub Actions** (`.github/workflows/pages.yml`): на push в `main` выполнить `npm ci`,
`npm run build`, затем `actions/upload-pages-artifact` с `path: dist` и `actions/deploy-pages`;
в Settings → Pages выбрать Source: *GitHub Actions*. Уровни (`src/data/levels.json`) лежат в
репозитории, поэтому `npm run gen` в CI не нужен.

После каждой публикации у сборки новый `contentHash` (виден в настройках как «Версия сборки»);
Service Worker обновит кэш и покажет тост «Доступно обновление → Перезапустить».

## Установка на iPhone

1. Открой опубликованный URL в **Safari** (другие браузеры на iOS не ставят веб-приложения).
2. Нажми «Поделиться» (квадрат со стрелкой внизу) → **«На экран „Домой“»** → «Добавить».
3. Запускай с иконки «Росчерк»: игра открывается на весь экран, без адресной строки, в
   портретной ориентации, и работает **офлайн** (второй запуск можно проверить в авиарежиме).

Пока игра открыта во вкладке Safari, на главном экране показывается карточка-инструкция;
прогресс во вкладке и в установленном приложении хранится отдельно — перенести его можно кодом
прогресса из настроек («Скопировать код прогресса» → «Вставить код прогресса»).

Проверить без iPhone: `npm run dev`, затем в Safari/Chrome на Mac включить эмуляцию
iPhone (390×844 или 375×667) — рисование, стены, второй палец, темы.
