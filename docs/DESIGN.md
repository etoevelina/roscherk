# Дизайн «Росчерка» по системе WORDS 1.2

Источник: `~/Downloads/outputs/words-design-system/` (index.html — спецификация, README.md,
`assets/words-ui-reference.png` — доска из 10 экранов, **главный визуальный эталон**). Этот файл
переносит эталон на «Росчерк»: пять режимов головоломок вместо одного кроссворда, русский интерфейс,
без монет и покупок. Заменяет оформление Lumin (§4.4 SPEC); механика режимов не меняется.

## 1. Принципы (из системы)
- **Информация прежде всего**: иерархия — масштабом, отступами и контрастом, а не рамками.
- **Мягко и точно**: скруглённая геометрия, тёплый фарфор, стеклянные 3D-объекты, мягкие тени.
- **Одно решающее действие**: почти-чёрный — только главная кнопка, активный прогресс, текущий
  уровень и завершение. Одна главная кнопка на экран.
- Один атмосферный оттенок на экран: шалфей — прогресс и спокойствие, лаванда — испытания и
  открытия, румяный и голубой — семейства карточек.
- Анимация объясняет связь и завершение; празднование утихает за секунду; без конфетти, тряски,
  красных экранов, прыгающих счётчиков. Reduce Motion убирает перемещения.

## 2. Токены и компоненты
- Токены — `src/styles/00-tokens.css` (`--w-*`, светлая и тёмная темы; прежние `--bg`, `--surface`,
  `--lm-*` переназначены на них — холсты режимов читают их через `readTheme`).
- Компоненты — `src/styles/05-kit.css` + `src/ui/kit.js`: `screen`, `header`, `tabBar`,
  `iconButton`, `button` (primary — чёрная пилюля ≥ 52px, со стрелкой `arrow`), `arrowCircle`,
  `art`, `progress`, `chips`, `seg`, `statCard`, `starsRow`, `row`, `switchControl`, `pill`,
  `formatDate`, `greeting`. Новые экраны строятся только из них + своих классов в своём файле
  `src/styles/NN-<экран>.css` (сборка подключает `src/styles/*.css` по имени).
- Шрифт — системный (SF Pro). Display 44/0.98 −6 %, Title 30 −4.5 %, H2 22, H3 17, Body 15/1.5,
  Caption 13, Eyebrow 11 капсом +16 %. Начертание ≤ 600 (полужирный — кнопки и буквы головоломки).
- Радиусы: карточки 24, крупные сцены 32, кнопки-пилюли 999, мелкие 12. Цели касания ≥ 44×44.
- Движение: нажатие 120 мс, распространение буквы 220 мс, шторка 360 мс (пружина без отскока),
  завершение 700 мс поэтапно.

## 3. 3D-графика
`assets/art/*.webp` (из PNG-мастеров `tools/art.py`) → `dist/art/`, в прекэше SW. В коде —
`art(name, class)`, картинка декоративная (`alt=""`), при ошибке загрузки убирает себя.

| файл | где |
| --- | --- |
| `pearl-ribbon` | онбординг (вертикальная лента справа), «Потоки» в «Режимах» |
| `glass-steps` | тёмная карточка «Продолжить путь» на главной |
| `sage-loop` | плитка «Слова» на главной, итог уровня, «Маршрут» в «Режимах» |
| `lavender-orb` | плитка «Испытания», «Слова» в «Режимах», экран «Испытания» |
| `rose-folds` | «Один штрих» в «Режимах» (румяное семейство) |
| `map-backdrop` | фон карты уровней (шёлк), шапка ежедневной |

«Карандаш» в «Режимах» — `glass-steps` на голубом семействе. Масштаб объектов 40–70 % карточки,
край обрезает объект; текст — вне ярких бликов.

## 4. Навигация
Нижняя навигация из 4 вкладок (`tabBar`): **Главная · Режимы · Ежедневная · Статистика**
(экраны `home`, `packs`, `daily`, `stats`). Активная — чернилами. Вкладки видны только на этих
четырёх экранах; карта уровней, игра, профиль, онбординг, «Испытания», «Специальные возможности»
открываются поверх, с круглой «назад» 44×44 в шапке. Профиль — круглая кнопка с инициалом в
шапке главной. Роутер — `app.go(name, params)` (src/main.js), без History API.

| экран | `app.go` | откуда |
| --- | --- | --- |
| Онбординг | `onboarding` | первый запуск (`settings.onboarded=false`, нет прогресса) |
| Главная | `home` | вкладка |
| Режимы | `packs` | вкладка; фильтр `params.filter` |
| Темы «Слов» | `wordPacks` | карточка «Слова» |
| Карта уровней | `levels` `{ modeId, pack? }` | карточка режима / темы |
| Игра | `game` (без изменений параметров) | узел карты, «Продолжить», ежедневная |
| Ежедневная | `daily` | вкладка, карточка на главной |
| Статистика | `stats` | вкладка |
| Профиль | `profile` (= `settings`) | аватар на главной |
| Специальные возможности | `a11y` | строка в профиле |
| Испытания | `challenges` | плитка на главной |
| Финал кампании | `campaignDone` | как раньше |

## 5. Экраны

### 5.1 Онбординг
Знак «Р О С Ч Е Р К» (wordmark, разрядка), Display в две строки: «Маленькие головоломки.» (ink) /
«Большая перспектива.» (тише, `.soft`). Подпись: «Линии, английские слова, физика и ежедневные
задачи — чтобы ум оставался любопытным.» Справа и снизу — `pearl-ribbon` крупно (≈ 70 % высоты),
обрезан краем. Внизу — одна чёрная пилюля «Начать →» (≈ 60 % ширины, слева, как в эталоне).
Нажатие → `settings.onboarded = true`, `app.go('home')`. Без карусели и без ввода имени.

### 5.2 Главная
- Шапка: слева «Доброе утро,» (тихо, 22) и имя (`settings.name`, 26, ink) на второй строке; без
  имени — одной строкой «Доброе утро» крупно. Справа пилюля серии 🔥 N (если серия > 0) и круглая
  кнопка профиля с инициалом (или иконкой `user`) → `profile`.
- Карточка **«Ежедневная»** (бумага): заголовок H2, дата «15 октября 2026», справа мини-превью
  (сетка 5×5 из квадратиков, как в эталоне; узор — из даты) и стрелка →. Решена — подпись
  «Решена · серия N дней» и галочка вместо стрелки. Нажатие → `daily`.
- Тёмная карточка **«Продолжить путь»**: две строки заголовка «Продолжить / путь» (белым, 24),
  ниже «Маршрут» и «Уровень 12», полоса прогресса режима (пройдено/всего), справа `glass-steps`.
  Данные: прерванная партия (`state.current`, кроме вчерашней ежедневной) → её уровень; иначе
  следующий уровень последнего режима с прогрессом; иначе «Маршрут · Уровень 1». Нажатие → игра.
- Две плитки рядом (высокие, ≈ 150px): **«Слова»** (шалфей, «Английские цитаты по темам»,
  `sage-loop` снизу справа) → `wordPacks`; **«Испытания»** (лаванда, «Бесконечность и рекорды»,
  `lavender-orb`) → `challenges`.
- Ниже — компактная карточка установки PWA (только вкладка Safari, как раньше: «Добавь на экран
  Домой», закрывается крестиком; `settings.installCardClosed`).
- Вкладки внизу.

### 5.3 Режимы (вкладка)
Крупный заголовок «Режимы», чипы-фильтры: **Все · Линии · Слова · Физика** (Линии — Маршрут,
Потоки, Один штрих). Широкие карточки высотой ≈ 120px с материальным градиентом и 3D-объектом
справа: название (H2), «100 уровней · пройдено 12», тонкий прогресс; у первой карточки — чёрная
круглая стрелка (как «Cities of the World»). Семейства: Маршрут — шалфей, Потоки — голубой,
Один штрих — румяный, Слова — лаванда, Карандаш — туман/голубой. Нажатие: «Слова» → `wordPacks`,
остальные → `levels {modeId}`.

### 5.4 Темы «Слов»
Шапка «‹ Слова». Чипы по группам тем (Все + 3–4 группы из тем в `words.json`, если они есть;
иначе только «Все»). Широкие карточки тем: название темы по-русски, «5 цитат · пройдено 2»,
семейства по кругу (шалфей, голубой, румяный, лаванда), 3D по кругу. Нажатие → `levels
{ modeId:'words', pack }` (карта темы).

### 5.5 Карта уровней
Фон — `map-backdrop` на всю высоту (прокручивается вместе с путём, `opacity .72`), поверх —
**диагональная пунктирная тропа**: узлы-круги 52px идут зигзагом (смещение ±30 % ширины по синусу),
соединены пунктиром. Состояния узлов: пройден — белый с номером и 1–3 точками-звёздами под ним;
**текущий** (следующий к прохождению) — чёрный с белым номером и кольцом прогресса, если есть
прерванная партия; открыт — белый; закрыт — полупрозрачный серый с замком; пропущен — белый с
пунктирной обводкой. Шапка: «‹», название режима/темы, справа пилюля ★ звёзд (сумма звёзд режима).
Внизу — плавающая карточка (бумага с размытием): «Глава 2 · Шарик» / «Тема: Путешествия» +
«Пройди всё, чтобы открыть следующую» + прогресс + стрелка → текущий уровень. Открытие уровней —
прежнее (`levelStatuses`, `openByChapter`, `campaignOnly`). Главы «Карандаша» — подписи на тропе.
При входе прокрутка к текущему узлу. 100 узлов — обычный DOM. Узел — кнопка с aria-label
«Уровень 12, пройден, 2 звезды из 3» / «закрыт».

### 5.6 Игра
- Шапка: «‹», «Уровень 12» по центру (ежедневная — «Ежедневная», бесконечность — «Бесконечность ·
  серия N»), справа пилюля-кнопка подсказки (лампочка) и шестерёнка → шторка быстрых настроек
  (звук, тема, вибрация; ссылка «Специальные возможности»).
- Поле режима — без изменений механики; фон холста — `--w-canvas`, поле — бумага.
- «Слова»: цитата сверху на бумажной панели, ниже определения и ответ, клавиатура QWERTY из
  светлых клавиш (`--w-key`), слева в нижнем ряду — шалфейная клавиша «Подсказка» с лампочкой
  (как в эталоне), справа — тёмная ⌫.
- Остальные режимы: нижняя панель — тихие кнопки «Отменить», «Сбросить» + подпись режима
  (как сейчас), подсказка — в шапке.
- **Шторка подсказок** (все режимы): затемнение, белая скруглённая шторка «Подсказка ×», 2–4
  варианта строками: иконка · название · справа цена «−★» (подсказка снимает звезду «без
  подсказок»). «Слова» — их `hintOptions` (открыть букву, убрать ошибки, открыть слово…); прочие —
  «Следующий ход» (`mode.hint`). Без «Купить монеты».

### 5.7 Итог уровня
Экран-карточка поверх поля: «Уровень пройден!» (Title), `sage-loop` крупно, **3 звезды**
(`starsFor`: пройден · без подсказок · идеально), цитата в кавычках (для «Слов» — разгаданная
цитата и автор; для остальных — короткая фраза режима), ряд из трёх метрик с иконками: ⏱ время ·
◎ ключевая метрика режима (первая строка `mode.stats`) · 🔥 серия. Кнопки: чёрная «Следующий
уровень →», вторая — обводка «К карте». Без конфетти: мягкое радиальное свечение и одно
восходящее появление звёзд (700 мс). Ежедневная — «Ежедневная решена!», «Серия N дней».

### 5.8 Ежедневная (вкладка)
Заголовок «Ежедневная», дата, справа иконка календаря. Полоса недели Пн–Вс (числа), сегодня —
шалфейная плашка, решённые дни — точка. Карточка-сцена (`map-backdrop` + мини-превью режима дня):
«Новая головоломка каждый день. Реши до полуночи, чтобы сохранить серию.» Строка «Серия · N дней»
(лучшая — тише). Главная кнопка «Начать головоломку →» / «Продолжить →» / решена — «Решена ✓»
неактивно и «Новая — завтра». Ниже — месяц точками (28 дней, `calendar()`).

### 5.9 Статистика (вкладка)
Заголовок «Статистика», сегменты **Неделя · Месяц · Всё время**, столбчатый график (`chart()`:
7 дней / 30 дней / 12 месяцев), столбцы шалфеем, текущий — чернилами, подписи снизу; над графиком
«N головоломок за неделю». Четыре карточки 2×2: «Уровней пройдено» · «Без подсказок» (%) ·
«Серия дней» · «Всего головоломок» (`totals()`). Ниже — прогресс по режимам (иконка, название,
пройдено/всего, звёзды). Данные — `state.activity` (пишется при каждой победе) и `progress`.

### 5.10 Профиль
Шапка «‹» и справа шестерёнка не нужна. Круглый аватар 76px с инициалом имени (градиент шалфей →
лаванда), имя (H2) — нажатие открывает диалог «Как тебя зовут?» (до 24 символов), подпись «Любо-
знательный ум. Исследователь линий.» Две карточки: 🔥 «N дней серии» и ★ «N звёзд». Список строк:
Тема (Системная/Светлая/Тёмная ›, шторка выбора) · Звук (переключатель) · Специальные возможности ›
· Перенос прогресса › (код: экспорт/импорт — как сейчас) · Номера в «Потоках» (переключатель, как
сейчас) · О приложении (версия, политика конфиденциальности) · «Сбросить прогресс» (красным, с
подтверждением). Всё, что умеет нынешний `settings.js`, сохраняется.

### 5.11 Специальные возможности
«Крупный текст в головоломке» (body.a11y-large: буквы и номера «Слов» +20 %, подписи холстов
крупнее) · «Меньше движения» (поверх системной) · «Контрастные номера» (body.a11y-contrast: номера
клеток чернилами, жирнее) · «Вибрация» (Лёгкая / Выкл). Сверху — живой пример: плитки «A 12 · R 4 ·
T 8», меняются сразу. Кнопка «Готово» справа в шапке.

### 5.12 Испытания
Шапка «‹ Испытания», сцена с `lavender-orb`, «Бесконечность» — серия уровней растущей сложности:
сегменты выбора режима (Маршрут · Потоки · Один штрих · Микс — как сейчас), «Лучшая серия: N»,
главная кнопка «Играть →» / «Продолжить →» (прерванная бесконечность).

## 6. Что сознательно не как в эталоне
- **Монет нет**: в эталоне подсказки стоят монеты и есть «Купить монеты». В «Росчерке» нет покупок
  и экономики — цена подсказки показана как «−★», в профиле вместо монет — звёзды.
- **Достижений и уведомлений нет**: строки профиля заменены настройками приложения.
- **Имя** — необязательное, задаётся в профиле; без имени приветствие без обращения.
- **Три звезды** — честные: пройден, без подсказок, идеально (`perfect` режима); звезда кампании
  (`star`) = все три.
- Тёмная тема — производная (в эталоне только светлая): тёплый графит, те же оттенки.

## 7. Проверка
- Каждый экран: 375 и 430 pt, светлая и тёмная, Dynamic Type 200 % без обрезки главного действия.
- Цели касания ≥ 44×44, VoiceOver: подписи кнопок-иконок, узлов карты, метрик, звёзд.
- Контраст текста ≥ 4.5:1 (подписи `--w-muted`), иконки и рамки ≥ 3:1.
- Reduce Motion (системный и свой): без перемещений и пружин.
- Офлайн: графика в прекэше; без неё экраны не ломаются.
